Exactly one line, written for the make.fun bounty "One-Line
Laugh-Off": the morning routine of a person who finally has one. Wake
up, check the phone, and apologise to the sleep schedule in writing —
formally, daily, and without any intention of changing.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
